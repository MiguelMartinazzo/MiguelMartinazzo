## Trabalho de Conclusão de Curso

Meu Trabalho de Conclusão de Curso foi focado em **Machine Learning**, com uma análise comparativa entre diferentes modelos supervisionados.

O estudo comparou os seguintes modelos:

- Decision Tree;
- Random Forest;
- Support Vector Machine;
- Extreme Learning Machine.

O objetivo foi avaliar o desempenho dos modelos na previsão de notas de filmes, utilizando uma base de dados com informações como gêneros, ano, votos e notas do IMDb.

Foram analisadas métricas como:

- Mean Squared Error;
- Mean Absolute Error;
- R² Score;
- Robustez com inserção de ruído;
- Interpretabilidade dos modelos;
- Tempo médio de processamento.

O modelo **Random Forest** apresentou o melhor equilíbrio geral entre precisão, robustez e desempenho, enquanto **Decision Tree** se destacou pela interpretabilidade, **SVM** pela robustez e **ELM** pela velocidade de treinamento.
